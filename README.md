# Shiva.J webshop

Stranica obrta SHIVA. J (unikatne rucno radene torbe).

- `index.html` - stranica (v47), `torbe.json` - ponuda (pise je admin), `img/` - fotografije
- `admin/`, `api/`, `data/`, `.htaccess` - PHP admin i API za Croadria hosting
- `router.php` - samo za lokalni test: `php -S 127.0.0.1:8090 -t . router.php`
- `docs/` - upute; postavljanje i održavanje na hostingu: `docs/UPUTE-OBJAVA-CROADRIA-v03.md`
- `tools/paket.py` - paket za prijenos na hosting (`dist/shivaj-vNN-prvi.zip` i `-nadogradnja.zip`)
- `torbe.primjer.json` - primjeri samo za lokalnu probu, ne objavljuje se
